# ПРОВЕРОЧНАЯ ЗА 10-09-2026

Решить задачу на С#, С++ и Python

## Задача 1

Напишите программу, которая запрашивает у пользователя его имя (строку) и возраст (целое число). Затем программа выводит приветствие в формате:

`"Привет, [имя]! Тебе [возраст] лет."`

## Задача 2. «Калькулятор суммы двух чисел»

Пользователь вводит два целых числа. Программа вычисляет и выводит их сумму, разность, произведение и частное от деления (результат деления вывести как вещественное число с двумя знаками после запятой).

## Задача 3. «Перевод температуры»

Пользователь вводит температуру в градусах Цельсия (вещественное число). Программа переводит её в градусы Фаренгейта по формуле: `F = C * 9 / 5 + 32` и в градусы Кельвина по формуле: K = C + 273.15. Результаты вывести с точностью до двух знаков после запятой.

## Задача 4. «Среднее арифметическое и преобразование типов»

Пользователь вводит три целых числа. Программа вычисляет их среднее арифметическое как вещественное число. Затем программа преобразует полученное среднее:

- в целое число (отбросив дробную часть);
- в строку с сообщением: `"Среднее значение: [число]"`.

Все три результата (вещественное среднее, целое среднее, строковое представление) выводятся на экран.

## Задача 5. «Калькулятор с проверкой деления на ноль»

Напишите программу, которая запрашивает у пользователя два числа (вещественные) и операцию: +, -, *, /. Программа должна выполнить соответствующее действие и вывести результат с точностью до трёх знаков. Важно: если выбрано деление и второе число равно нулю, программа не должна выполнять деление, а вместо результата выводить сообщение: "Ошибка: деление на ноль!". Также программа должна корректно обрабатывать случай, когда пользователь ввёл неизвестную операцию — выводить: "Неизвестная операция".

## Задача 6

Пользователь вводит три вещественных числа — коэффициенты квадратного уравнения a, b и c *(вида ax² + bx + c = 0)*. 

Программа должна:

- Проверить, что коэффициент a не равен нулю *(иначе это не квадратное уравнение)*.
- Вычислить дискриминант по формуле: `D = b² − 4ac`
- Вывести значение дискриминанта с точностью до двух знаков после запятой.

Дополнительно определить и вывести количество корней:

- если D > 0 — «Два корня»,
- если D = 0 — «Один корень»,
- если D < 0 — «Корней нет».
