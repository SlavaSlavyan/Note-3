Стек (**Stack**) — это структура данных, работающая по принципу **LIFO** (*Last In, First Out* — «последним пришёл, первым вышел»).

Представь стопку тарелок:

- Кладёшь тарелку сверху — `push`.
- Берёшь тарелку сверху — `pop`.
- Посмотреть верхнюю, не снимая — `peek`.
- Нельзя взять нижнюю, не сняв верхние.

Именно так работает стек.

## Зачем нужен стек?

Стек удобно использовать, когда данные нужно обрабатывать в обратном порядке:

- отмена действий (Undo/Redo);
- проверка скобочных последовательностей;
- переворот строки;
- обход структур данных;
- вызовы методов и рекурсия.

## Способы реализации стека в Java

| Способ       | Класс / интерфейс                              | Когда использовать                           |
| ------------ | ---------------------------------------------- | -------------------------------------------- |
| Классический | `java.util.Stack`                              | Устаревший, но простой и удобен для изучения |
| Современный  | `java.util.ArrayDeque` через `java.util.Deque` | Рекомендуется                                |
> В Java рекомендуется использовать интерфейс `Deque` и его реализацию `ArrayDeque` вместо классического класса `java.util.Stack`, так как **`Stack` является устаревшим (legacy) классом из Java 1.0 с серьезными архитектурными и производительными недостатками**. Официальная документация Oracle прямо советует использовать `Deque` для реализации стеков.

## 1. Класс `Stack` — классический

```java
import java.util.Stack;

Stack<Integer> stack = new Stack<>();
Stack<String> names = new Stack<>();
```

### Основные методы `Stack`

| Метод              | Что делает                                                         | Пример                        |
| ------------------ | ------------------------------------------------------------------ | ----------------------------- |
| `push(E item)`     | Кладёт элемент на вершину стека                                    | `stack.push(10);`             |
| `pop()`            | Удаляет и возвращает верхний элемент                               | `int x = stack.pop();`        |
| `peek()`           | Возвращает верхний элемент, не удаляя его                          | `int x = stack.peek();`       |
| `empty()`          | Проверяет, пуст ли стек                                            | `if (stack.empty()) { ... }`  |
| `search(Object o)` | Возвращает позицию элемента от вершины или `-1`, если элемента нет | `int pos = stack.search(10);` |

### Пример

```java
import java.util.Stack;

public class StackExample {
    public static void main(String[] args) {
        Stack<Integer> stack = new Stack<>();

        stack.push(1);
        stack.push(2);
        stack.push(3);

        System.out.println(stack.peek()); // 3
        System.out.println(stack.pop());  // 3
        System.out.println(stack);        // [1, 2]
    }
}
```

## 2. `ArrayDeque` — современный стек

`ArrayDeque` — двусторонняя очередь, но её можно использовать как стек.

```java
import java.util.ArrayDeque;
import java.util.Deque;

Deque<Integer> stack = new ArrayDeque<>();
```

### Основные методы `ArrayDeque` / `Deque` при использовании как стек

| Метод | Что делает | Пример |
|---|---|---|
| `push(E e)` | Добавляет элемент на вершину стека | `stack.push(10);` |
| `pop()` | Удаляет и возвращает верхний элемент | `int x = stack.pop();` |
| `peek()` | Возвращает верхний элемент, не удаляя его | `int x = stack.peek();` |
| `isEmpty()` | Проверяет, пуст ли стек | `if (stack.isEmpty()) { ... }` |
| `size()` | Возвращает количество элементов | `int n = stack.size();` |
| `clear()` | Очищает стек | `stack.clear();` |

### Пример

```java
import java.util.ArrayDeque;
import java.util.Deque;

public class ArrayDequeStackExample {
    public static void main(String[] args) {
        Deque<Integer> stack = new ArrayDeque<>();

        stack.push(1);
        stack.push(2);
        stack.push(3);

        System.out.println(stack.peek()); // 3
        System.out.println(stack.pop());  // 3
        System.out.println(stack);        // [2, 1]
    }
}
```

## `Stack` vs `ArrayDeque`: что выбрать

| Свойство | `Stack` | `ArrayDeque` |
|---|---|---|
| Скорость | Медленнее: методы синхронизированы | Быстрее: не синхронизирован |
| Значение `null` | Допускает `null` | Не допускает `null`, бросает `NullPointerException` |
| Статус | Устаревший класс (legacy) | Рекомендуемый современный вариант |
| Интерфейс | Класс `Stack` | Реализует `Deque` |
| Потокобезопасность | Синхронизирован | Не синхронизирован |

**Вывод:** для новых программ в однопоточном коде обычно выбирают `ArrayDeque`. `Stack` удобен для изучения и поддержки старого кода.
