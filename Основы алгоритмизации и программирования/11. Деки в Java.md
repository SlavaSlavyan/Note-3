**Deque** (произносится «дек», сокращение от Double Ended QUEue) — это двусторонняя очередь. В отличие от обычной очереди, где элементы добавляются с одного конца, а извлекаются с другого, дек позволяет добавлять, удалять и просматривать элементы с обоих концов.

Аналогия: Представь трубу, в которую можно класть и брать мячики с обеих сторон. Это и есть дек.

**Ключевая особенность:** Deque может работать и как стек, и как очередь — всё зависит от того, какие методы ты используешь.

### Зачем нужен дек?

Дек удобно использовать в задачах, где требуется доступ к элементам с обоих концов:

- проверка палиндрома;
    
- скользящее окно (поиск максимума/минимума/медианы);
    
- реализация стека и очереди одновременно;
    
- обход графа в глубину/ширину;
    
- кэширование с вытеснением с обоих концов;
    
- переворот части последовательности.
    

### Способ реализации Деков в Java и отличия

В Java интерфейс `Deque` находится в пакете `java.util`. Основные реализации:

- `ArrayDeque` — на основе динамического массива;
    
- `LinkedList` — на основе двусвязного списка.
    

Отличия:

- `ArrayDeque` быстрее и использует меньше памяти, но не поддерживает `null`;
    
- `LinkedList` поддерживает `null`, но требует больше памяти и медленнее при частых операциях с концами.
    

**Пример создания дека:**

```java
import java.util.Deque;
import java.util.ArrayDeque;
Deque<Integer> deque = new ArrayDeque<>();
Deque<String> names = new ArrayDeque<>();
```
### Основные методы реализации через ArrayDeque (часть 1)

|Метод|Что делает|Пример|
|---|---|---|
|`addFirst(E e)`|Добавляет элемент в начало дека|`deque.addFirst(1);`|
|`addLast(E e)`|Добавляет элемент в конец дека|`deque.addLast(2);`|
|`removeFirst()`|Удаляет и возвращает первый элемент|`deque.removeFirst();`|
|`removeLast()`|Удаляет и возвращает последний элемент|`deque.removeLast();`|
|`getFirst()`|Возвращает первый элемент без удаления|`deque.getFirst();`|
|`getLast()`|Возвращает последний элемент без удаления|`deque.getLast();`|

### Основные методы реализации через ArrayDeque (часть 2)

|Метод|Что делает|Пример|
|---|---|---|
|`offerFirst(E e)`|Добавляет элемент в начало, возвращает `boolean`|`deque.offerFirst(1);`|
|`offerLast(E e)`|Добавляет элемент в конец, возвращает `boolean`|`deque.offerLast(2);`|
|`pollFirst()`|Удаляет и возвращает первый элемент или `null`|`deque.pollFirst();`|
|`pollLast()`|Удаляет и возвращает последний элемент или `null`|`deque.pollLast();`|
|`peekFirst()`|Возвращает первый элемент или `null`|`deque.peekFirst();`|
|`peekLast()`|Возвращает последний элемент или `null`|`deque.peekLast();`|
|`push(E e)`|Добавляет элемент в начало (как стек)|`deque.push(1);`|
|`pop()`|Удаляет и возвращает первый элемент (как стек)|`deque.pop();`|

**Пример:**

```java
Deque<Integer> deque = new ArrayDeque<>();
deque.addFirst(1);
deque.addLast(2);
deque.offerFirst(0);
deque.offerLast(3);
System.out.println(deque); // [0, 1, 2, 3]
System.out.println(deque.pollFirst()); // 0
System.out.println(deque.pollLast()); // 3
System.out.println(deque.peekFirst()); // 1
System.out.println(deque.peekLast()); // 2
```
### Сравнительная таблица ArrayDeque vs LinkedList

|Критерии|ArrayDeque|LinkedList|
|---|---|---|
|Производительность добавления/удаления с концов|O(1), очень быстро|O(1), но с накладными расходами на создание узлов|
|Использование памяти|Меньше (массив)|Больше (узлы с ссылками)|
|Поддержка `null`|Не поддерживает|Поддерживает|
|Доступ по индексу|Нет|Есть (`get(int)`), но O(n)|
|Вставка/удаление в середину|Не поддерживается эффективно|Поддерживается, O(1) при наличии итератора|
|Использование как стек/очередь|Предпочтительно|Возможно, но медленнее|
|Итерация|Быстрее|Медленнее|
