# Задача 2: Проверка скобочных последовательностей

Пользователь вводит строку со скобками `()`, `[]`, `{}`. Проверь, правильно ли они расставлены:

- каждая открывающая имеет парную закрывающую;
- порядок соблюдён, нельзя `([)]`.

**Примеры:**

| Ввод | Результат |
|---|---|
| `()` | `true` |
| `(())` | `true` |
| `([])` | `true` |
| `{[()]}` | `true` |
| `(()` | `false` |
| `([)]` | `false` |
| `((` | `false` |
| `)` | `false` |

**Идея решения:** открывающую скобку кладём в стек. Для закрывающей проверяем, что стек не пуст и на вершине лежит парная открывающая скобка.
