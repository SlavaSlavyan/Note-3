# Задача 3: Undo/Redo — отмена и повтор действий

Представьте, что пользуетесь текстовым редактором, как Word или Блокнот. Нажимаете `Ctrl+Z` — и последнее действие отменяется. Нажимаете `Ctrl+Y` — и отменённое действие возвращается.

Нужно смоделировать это в консоли. Программа должна уметь выполнять четыре команды, а пользователь через меню выбирает нужную:

1. `doAction(String action)` — выполнить действие. Как будто «делаешь» что-то в редакторе. Например, печатаешь букву.
   - Действие запоминается в истории.
   - После этого его можно отменить.

2. `undo()` — отменить последнее действие. Берёт последнее выполненное действие и «отменяет» его.
   - Действие перемещается в «список отменённых».
   - Оттуда его потом можно вернуть через `redo`.

3. `redo()` — вернуть отменённое действие. Берёт последнее отменённое действие и «возвращает» его.
   - Действие перемещается обратно в «список выполненных».

4. `print()` — показать историю.
   - Выводит текущую историю действий.

**Важно:** когда делаете новое действие после отмены — всё, что было отменено, «сгорает». Вернуть его уже нельзя.

**Аналогия:** вы напечатали «А», «В», «С». Отменили «С» и «В». Теперь напечатали «D». Вернуть «С» и «В» уже нельзя — история пошла по другой ветке.

**Подсказка по реализации:** нужны два стека:

- `undoStack` — выполненные действия;
- `redoStack` — отменённые действия.

При `doAction` добавляем действие в `undoStack` и очищаем `redoStack`. При `undo` перекладываем верхний элемент из `undoStack` в `redoStack`. При `redo` — наоборот.
