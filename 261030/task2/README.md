# Задача 2. Анализ текстового файла

**Условие:**

Дан файл `text.txt` (например, созданный в задаче 1.1 или вручную). Нужно прочитать его и вывести статистику:

- количество строк,
- общее количество слов,
- самое длинное слово,
- количество строк, содержащих слово `«Java»`.

**Требования:**

- Читать через `BufferedReader` построчно.
- Слова разделяются пробелами (используй `split("\\s+")`).
- Если файл пуст — вывести `«Файл пуст»`.
- Обработать `IOException`.

**Пример файла `text.txt`:**

```text
Java это язык
Python тоже язык
Java и Python популярны
```

**Ожидаемый вывод:**

```text
Строк: 3
Слов: 10
Самое длинное слово: популярны
Строк с "Java": 2
```
