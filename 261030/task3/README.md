# Задача 3. Копирование с фильтрацией

### Условие:

Дан файл `input.txt` с текстом. Нужно создать `output.txt`, в который попадут только строки длиной больше **10** символов, при этом:

- каждая строка нумеруется `(1: ..., 2: ...)`,
- пустые строки пропускаются,
- в конце — строка `--- Конец ---`.

### Требования:

- Прочитать `input.txt` через `BufferedReader`.
- Записать результат в `output.txt` через `BufferedWriter` (с перезаписью, не дозаписью).
- Использовать два `try-with-resources` (или один общий с двумя ресурсами).
- Считать, сколько строк отфильтровано, вывести в консоль.

### Пример `input.txt`:

```text
Короткая
Это строка подлиннее
Ещё одна довольно длинная строка
123
Финальная строка тоже длинная
```

### Ожидаемый `output.txt`:

```text
1: Это строка подлиннее
2: Ещё одна довольно длинная строка
3: Финальная строка тоже длинная
--- Конец ---
```

### Консоль:

```text
Отфильтровано 3 строк
```
