# Задача 1. Дневник заметок

**Условие:** Ты пишешь простое приложение «Дневник». Пользователь вводит заметки с клавиатуры, каждая сохраняется в файл `diary.txt` с новой строки. 

Программа работает, пока пользователь не введёт слово выход.

**Требования:**

- Использовать `BufferedWriter` с режимом дозаписи `(FileWriter(..., true))` — чтобы старые заметки не стирались.
- Каждая заметка — с новой строки.
- При вводе выход — завершить работу и вывести `«Сохранено N заметок»`.

**Пример работы:**

```text
Введите заметку (или 'выход'): Купить хлеб
Введите заметку (или 'выход'): Позвонить маме
Введите заметку (или 'выход'): выход
Сохранено 2 заметок
```
