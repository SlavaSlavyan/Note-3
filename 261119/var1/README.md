# Общие требования:

1. Игра для двух игроков на одном компьютере (по очереди вводят ход с клавиатуры).
2. Поле 3×3, клетки нумеруются 1–3.
3. Игрок 1 играет за Х, игрок 2 — за О.
4. После каждого хода выводится текущее состояние поля.
5. Проверяется:
   - победа (3 в ряд по горизонтали, вертикали, диагонали);
   - ничья (поле заполнено, победителя нет).
6. Некорректный ввод (не число, число вне 1–3, занятая клетка) не должен ломать игру — нужно попросить ввести ход заново.
7. В конце выводится результат: кто победил или «Ничья!».
