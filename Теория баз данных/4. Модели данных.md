**Модель данных** - совокупность правил порождения структуры данных в базе данных, операций над ними, а так же ограничений целостности. Способ организации каких либо объектов в рамках определённой системы.

**Модель базы данных** - это логическое описание базы данных, которая реально существует.
### Виды баз данных

1. **Иерархическая модель** - модель данных где используется представление базы данных в виде древовидной структуры. 
	- Доступ между соседними узлами дерева является недоступным
	- Применимы не ко всем областям
	- Высокая эффективность (быстрый поиск)
	- Сложность модификаций и добавления данных
	- Отсутствие строгой математической основы

2. **Сетевая модель** - модель, где база данных представляется в виде графа
	- Полнота для любой предметной области
	- Сложность при проектировании
	- Отсутствие физической независимости данных
	- Отсутствие строгой математической основы

3. **Реляционная модель** - модель данных, в которой представление базы данных основывается на специальных разделах математики, таких как теория множест, теория придикта первого порядка
4. Не реляционная модель (NoSQL) - это класс систем управления БД, которые отказались от традиционной табличной структуры\жёстко заданной системы.
