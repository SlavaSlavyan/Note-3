Параметры и SQL Injection
SQl нельзя строить конкатенацией пользовательских строк. Параметры отделяют SQL код от данных
Опасная конкатенация  
```
var sql = $"SELECT id, name FROM students WHERE name = '{name}'";
```
Проблема возникает, когда значение name, может содержать специальные символы или фрагменты кода. В худшем случае это дает возможность изменить смысл запроса
Это и есть SQL Injection
Безопасный вариант  
```
await using var command = new NpgsqlCommand( "SELECT id, name FROM students WHERE name = $1", connection);
command.Parameters.AddWithValue(name);
await using var reader = await command.ExecuteReaderAsync();
```
Параметры предназначены для обозначения данных, а не для частей синтаксической структуры SQL. 
Нельзя надежно сделать SELECT * FROM $1, передав имя таблицы, как обычный параметр. Если имя таблицы/колонки должно быть динамическим, нужно использовать белый список допустимых идентификаторов или специальные механизмы "безопасного" акцентирования, предоставляемое конкретным драйвером
Типы параметров
npgsql старается вывести PostgreSQL тип из .NET. Во многих случаях этого достаточно, однако PostgreSQL имеет строгую типизацию и для некоторого типа(JSONb, специфические PostgreSQL типы), может потребоваться явное указание npgsqlDbType 
```
command.Parameters.AddWithValue( NpgsqlDbType.Jsonb, jsonText);
```
NpgsqlDbType - Npgsql-специфичное перечисление. DbType - более переносимый ADO.NET API. Выбор между ними зависит от того, насколько вам нужна переносимость между провайдерами.

### Транзакции COMMIT и ROLLBACK
Транзакции объединяют несколько операций БД в одну логическую единицу. Либо все изменения подтверждаются либо все изменения отменяются

Пример:
Перевод денег между счетами. Если деньги списались со счета А, но не зачислились на счет В, состояние системы испорчено. Обе операции должны быть частью одной транзакции

### ACID - четыре свойства транзакции
Atomacity(Атомарность) - все операции выполняются вместе либо не применяются вовсе
Consistency(Согласованность) - транзакция сохраняет установленные правила и ограничения данных 
Isolation(Изоляция) - Параллельные транзакции не должны создавать запрещенные промежуточные эффекты, конкретные гарантии зависят от уровня изоляции
Durability(Надежность фиксации) - зафиксированные изменения должны сохраняться согласно гарантиям СУБД

### Асинхронный ADO.NET
Обращение к БД требует сетевого взаимодействия: Приложение отправляет запрос и ждет ответ сервера. Асинхронные методы позволяют ADO.NET не простаивать в ожидании ответа, а выполнять другую работу
Асинхронность сама по себе не гарантирует, что SQL станет выполняться быстрее. Она особенно полезна в веб серверах, графических приложениях и программах, которые во время обращения к БД должны оставаться отзывчивыми

```csharp
using Npgsql;

string connectionString = Environment.GetEnvironmentVariable("FITNESS_DB")
    ?? throw new InvalidOperationException("Не задана переменная FITNESS_DB.");

await using var dataSource = NpgsqlDataSource.Create(connectionString);

await using var command = dataSource.CreateCommand("""
    SELECT client_id, first_name, last_name
    FROM clients
    ORDER BY client_id;
    """);

await using var reader = await command.ExecuteReaderAsync();

while (await reader.ReadAsync())
{
    int id = reader.GetInt32(0);
    string firstName = reader.GetString(1);
    string lastName = reader.GetString(2);
    Console.WriteLine($"{id}: {firstName} {lastName}");
}
```
В современном C# можно использовать await на верхнем уровне программы (Program.cs) в консольном проекте. Если проект создан на старой версии C#/.NET, разместите код внутри static async Task Main().

### Передача CancellationToken
Токен отмены позволяет запросить прекращение операции, например, если пользователь закрыл окно или клиент отменил http запрос. Отмена со стороны приложения не означает, что любая операция на сервере мгновенно остановится, поведение зависит от состояния запроса драйвера и сервера.

## Класс доступа к данным и паттерн Repository
Когда все приложения находится в main, там одновременно оказываются ввод пользователя, SQl, преобразования результатов, бизнес правила и вывод. По мере роста проекта такой код сложно понимать и изменять. 
разделение ответственности: 
1) Точка входа\Интерфейс: Получает ввод и показывает результат
2) Класс доступа к данным: Знает SQl и способы чтения/изменения данных
3) Модель: описывает данные клиента в С#
4) Бизнес-логика: определяет правила - например, можно ли регистрировать клиента с определенным статусом?
Repository - распространённый способ скрыть детали получения и сохранения данных за набором методов, например, GetAllAsync, GetByIdAsync, etc..

Репозиторий 

```csharp
using Npgsql;

public sealed class ClientRepository
{
    private readonly NpgsqlDataSource _dataSource;

    public ClientRepository(NpgsqlDataSource dataSource)
    {
        _dataSource = dataSource;
    }

    public async Task<List<Client>> GetAllAsync(
        CancellationToken cancellationToken = default)
    {
        var clients = new List<Client>();

        await using var command = _dataSource.CreateCommand("""
            SELECT client_id, first_name, last_name, phone, email, status
            FROM clients
            ORDER BY client_id;
            """);

        await using var reader = await command.ExecuteReaderAsync(cancellationToken);

        while (await reader.ReadAsync(cancellationToken))
            clients.Add(MapClient(reader));

        return clients;
    }

    public async Task<Client?> GetByIdAsync(
        int clientId,
        CancellationToken cancellationToken = default)
    {
        await using var command = _dataSource.CreateCommand("""
            SELECT client_id, first_name, last_name, phone, email, status
            FROM clients
            WHERE client_id = $1;
            """);
        command.Parameters.AddWithValue(clientId);

        await using var reader = await command.ExecuteReaderAsync(cancellationToken);
        if (!await reader.ReadAsync(cancellationToken))
            return null;

        return MapClient(reader);
    }

    public async Task<int> CreateAsync(
        string firstName,
        string lastName,
        string? phone,
        string? email,
        CancellationToken cancellationToken = default)
    {
        if (string.IsNullOrWhiteSpace(firstName))
            throw new ArgumentException("Имя обязательно.", nameof(firstName));
        if (string.IsNullOrWhiteSpace(lastName))
            throw new ArgumentException("Фамилия обязательна.", nameof(lastName));

        await using var command = _dataSource.CreateCommand("""
            INSERT INTO clients
                (first_name, last_name, phone, email, registration_date, status)
            VALUES
                ($1, $2, $3, $4, CURRENT_DATE, $5)
            RETURNING client_id;
            """);

        command.Parameters.AddWithValue(firstName.Trim());
        command.Parameters.AddWithValue(lastName.Trim());
        command.Parameters.AddWithValue((object?)phone ?? DBNull.Value);
        command.Parameters.AddWithValue((object?)email ?? DBNull.Value);
        command.Parameters.AddWithValue("active");

        object? result = await command.ExecuteScalarAsync(cancellationToken);
        return Convert.ToInt32(result);
    }

    public async Task<bool> UpdatePhoneAsync(
        int clientId,
        string? phone,
        CancellationToken cancellationToken = default)
    {
        await using var command = _dataSource.CreateCommand("""
            UPDATE clients
            SET phone = $1
            WHERE client_id = $2;
            """);

        command.Parameters.AddWithValue((object?)phone ?? DBNull.Value);
        command.Parameters.AddWithValue(clientId);

        int changedRows = await command.ExecuteNonQueryAsync(cancellationToken);
        return changedRows == 1;
    }

    public async Task<bool> DeleteAsync(
        int clientId,
        CancellationToken cancellationToken = default)
    {
        await using var command = _dataSource.CreateCommand("""
            DELETE FROM clients
            WHERE client_id = $1;
            """);
        command.Parameters.AddWithValue(clientId);

        int deletedRows = await command.ExecuteNonQueryAsync(cancellationToken);
        return deletedRows == 1;
    }

    private static Client MapClient(NpgsqlDataReader reader)
    {
        return new Client
        {
            ClientId = reader.GetInt32(0),
            FirstName = reader.GetString(1),
            LastName = reader.GetString(2),
            Phone = reader.IsDBNull(3) ? null : reader.GetString(3),
            Email = reader.IsDBNull(4) ? null : reader.GetString(4),
            Status = reader.GetString(5)
        };
    }
}
```
