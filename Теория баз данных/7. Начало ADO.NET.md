API - программный интерфейс
ADO.NET - это набор API.NET для работы с источниками данных или же — это технология (набор классов и API) в рамках платформы Microsoft .NET Framework, которая позволяет приложениям получать доступ к данным из разных источников: реляционных баз данных (например, Microsoft SQL Server, Microsoft Access, Oracle), а также других источников вроде XML-файлов или текстовых данных. Её название расшифровывается как ActiveX Data Object для .NET.
ADO.NET не является отдельной БД и не является ORM. Это инфраструктура доступа к данным. Она дает приложению стандартизированную модель работы, а конкретно провайдер переводит эту модель в протокол и особенности конкретной СУБД
Data Provider - это библиотека, которая знает как общаться с конкретным источником данных. Для PostgreSQL используется npgsql

Минимальный пример 
```
using Npgsql;
var connectionString ="Host=localhost;
Port=5432;
Database=academy;
Username=app;
Password=secret";
await using var connection = new NpgsqlConnection(connectionString);
await connection.OpenAsync();
Console.WriteLine("Соединение установлено.");

```
Dapper - микро ORM. Он не пытается скрыть SQL полностью, вы по прежнему пишите SQL, но библиотека сокращает ручной код, чтение строк и сопоставление колонок с C# объектами
EFCore - Entity Framework Core - это ORM. Вы описывается модель сущностей, используя DbContext и LINQ - Efcore переводит запросы в SQL, материализует результаты в объекты и умеет отслеживать изменения сущностей.
DbContext умеет хранить состояния отслеживаемых объектов, а Save Changes применяет изменения к базе данных
В ADO.NET вы самостоятельно задаете SQL, параметры и способ чтения результата
Если запрос вернул id, name, email, именно ваш код ваш код решает какие свойства объектов попадут в эти значения
ADO.NET не отслеживает автоматически, что мы изменили свойства объекта после SELECT

DbConnection - это абстрактный базовый ADO.NET, представляющий соединение с источником данных. Конкретный провайдер реализует его, например, npgsqlConnection.
У Connection есть строка подключения, состояния, операции открытия закрытия.
На уровне ADO.NET нас интересует сам принцип, а не только конкретный класс PostgreSQL
DbCommand - это абстрактные представления команды для источника данных. В нем находится текст команды или другой способ ее представления.
![[Pasted image 20261006101242.png]]
DbParameter - это представление значения, которое передается в команду отдельно от текста SQL.
Parameter важен по двум причинам
1. Он отделяет данные от кода SQL и защищает от SQL injection, при корректном использовани
2. Он передает значения как значение определенного типа, а не как кусок текста, которые нужно строить в SQL
DbDataReader - это потоковый объект чтения набора результатов, чтение происходит последовательно вперед по строкам, это удобно для больших выборок, потому что не требуется заранее материализовать весь набор в Data Table или список.
DbTransaction - это объект, объединяющий несколько операций в БД в одну атомарную единицу работы.
