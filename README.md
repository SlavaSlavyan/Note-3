# CPP

В этой ветке будут выкладываться мои домашние задания по предмету **"Объектно-ориентированное программирование с использованием языка C++ РПО"**. Этого предмета НЕТ на третьем курме, но к сожалению у меня много долгов по нему со второго курса <(＿　＿)>

Так что тут появятся мои долги.

## Логика

Каждое задание представленно папкой с файлами. Папки именуются датой выкладывания домашнего задания в формате **год|месяц|день**.

Так же большинство заданий внутри себя имеют схожую структуру:

- **README.md** - текст задания
- **build.exe** - скомпилированное задание для проверки работоспособности
- **program.cpp** - точка входа в программу
- **src/** - дополнительные файлы .cpp
- **include/** - дополнительные файлы .hpp

Сами задания отправляются проверяющему ссылкой на репозиторий.
