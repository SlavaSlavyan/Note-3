# OBSIDIAN

Данная ветка создана для электронных конспектов. Для работы с конспектами я использую бесплатное ПО [obsidian](https://obsidian.md/) Возможно конспектов конечно вообще не будет, но ветку я всё равно сделал (￣y▽,￣)╭ При требовании преподавателя я могу скинуть ссылку на конкретный конспект, ну или же вы можете посмотреть все конспекты целиком. 

- НЕ содержит домашних заданий! 
- Сканы письменных конспектов находятся в другой ветке!

## Логика

Каждый предмет имеет свою отдельную папку.

Чаще всего каждый отдельный конспект представлен в формате **markdown**. Файлы именуются в формате номера и темы пары. Если тема довольно объёмная и растягивается на несколько дней, то приемлемо использовать номера по типу **1-2**. Так же каждый файл должен иметь даты написания внутри себя.

При использовании картинок внутри конспекта они могут храниться в папке **\_assets/**.

Так же конечные конспекты переносятся в конечный *"сборник"* в формате **word**, который в дальнейшем можно удобно распечатать.

Любые проверочные работы, домашние задания, презентации, проекты, письменные конспекты или иные файлы связанные с конкретными предметами переносятся в **другие ветки**! Здесь хранятся **ТОЛЬКО** электронные конспекты!
