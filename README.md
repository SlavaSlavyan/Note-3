# PHILOSOPHY

В этой ветке будут выкладываться мои домашние задания по предмету **"Основы философии"**. По идее это поможет нам мыслить за рамками обычного и видеть мир более объёмно, ноо хзхз если честно.

Так же желательно учесть что нам обещали не делать проверочных работ, и проверкой наших знаний будет экзамен ближе к новому году.

## Логика

Каждое задание имеет либо свой отдельный файл, либо отдельную папку.

Чаще всего задания будут представлены единым **word** или **pdf** файлом. Файлы именуются датой выкладывания домашнего задания в формате **год|месяц|день**.

Сами задания отправляются проверяющему в формате **pdf** в **omni** (если это не папка). Ссылки на это хранилище будут вставляться в комментарий к заданию.
