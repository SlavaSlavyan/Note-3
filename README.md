## Логика

Каждое задание имеет либо свой отдельный файл, либо отдельную папку.

Чаще всего задания будут представлены единым **word** файлом. Файлы именуются датой выкладывания домашнего задания в формате **год|месяц|день**.

Сами задания отправляются проверяющему в формате **pdf** в **omni** (если это не папка). Ссылки на это хранилище будут вставляться в комментарий к заданию.
