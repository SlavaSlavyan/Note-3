## Логика

Каждое задание имеет либо свой отдельный файл, либо отдельную папку.

Чаще всего задания будут представлены папкой с `java` проектом. Файлы именуются датой выкладывания домашнего задания в формате `год|месяц|день`.

Сами задания отправляются проверяющему в формате **pdf** в **omni** (если это не папка). Ссылки на это хранилище будут вставляться в комментарий к заданию.

## Как запустить проект Java

Большая часть заданий выполнена ввиде `Java` проектов. Я пользуюсь IDE **Visual Studio Code**, так что данная инструкция пригодна только для неё *(наверное)*.

1. Сначала в папке с заданием (где есть папка src) добавте папку `.vscode`
2. Затем, создайте новый файл внутри это папки `settings.json`.
3. Задайте шаблон проекта. Базовый шаблон без дополнительных библиотек вы можете скопировать от сюда.

**Базовый шаблон настроек:**
```json
{
    "java.project.sourcePaths": ["src"],
    "java.project.outputPath": "bin",
    "java.project.referencedLibraries": [
        "lib/**/*.jar"
    ]
}
```
