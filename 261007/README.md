## Задача «Пиццерия»

**Цель:** закрепить все четыре столпа ООП: **инкапсуляцию, наследование, полиморфизм и абстракцию**.

### Сюжет

Пиццерия принимает заказы. В меню есть три вида позиций: **пицца**, **напиток** и **десерт**. У каждой позиции своя логика расчёта цены. Кассир должен уметь добавлять позиции в заказ и печатать чек, не зная, что именно за позиция перед ним.

---

### Требования

#### 1. Абстрактный класс `MenuItem` (общая позиция меню)

Поля и свойства:
- `private string _name` — название;
- `protected decimal _basePrice` — базовая цена (доступна наследникам, но не снаружи);
- `public string Name { get; }` — только для чтения.

Конструктор принимает `name` и `basePrice`, причём если `basePrice < 0` — бросает `ArgumentException`.

Абстрактные и виртуальные члены:
```csharp
public abstract decimal GetFinalPrice();
public abstract string GetInfo();
public virtual string GetCategory() => "Позиция меню";
```

#### 2. Три класса-наследника

| Класс   | Дополнительные данные | Правило цены |
|---      |---                    |---           |
| `Pizza` | `int ToppingsCount` — число топпингов | `_basePrice + ToppingsCount * 50` |
| `Drink` | `int VolumeMl` — объём в мл | `_basePrice + VolumeMl * 0.5m` |
| `Dessert` | `bool IsTodayFresh` — свежий ли сегодня | если свежий — `_basePrice`, иначе `_basePrice * 0.7m`|

Каждый класс обязан переопределить `GetFinalPrice()`, `GetInfo()` и `GetCategory()`.

Пример `GetInfo()` для пиццы:
```
Пицца «Маргарита», топпингов: 3, итого: 550 руб.
```

#### 3. Интерфейс `IDiscountable`

```csharp
public interface IDiscountable
{
    decimal ApplyDiscount(decimal percent);
    string GetDiscountInfo();
}
```

Его должны реализовать **только** `Pizza` и `Dessert` (напитки не участвуют в акции). Каждый реализует по-своему:
- `Pizza` — скидка 5% дополнительно, если топпингов больше 3;
- `Dessert` — скидка 10%, если десерт не свежий (распродажа).

Метод `ApplyDiscount(percent)` возвращает новую цену с учётом и внешней скидки, и внутренней логики класса.

#### 4. Класс `Order` (инкапсуляция)

Поля:
```csharp
private readonly List<MenuItem> _items = new();
private const int MaxItems = 20;
```

Методы:
- `void Add(MenuItem item)` — добавляет позицию. Если `item == null` — `ArgumentNullException`. Если в заказе уже `MaxItems` позиций — `InvalidOperationException`.
- `IReadOnlyList<MenuItem> GetItems()` — возвращает позиции **только для чтения** (не даёт изменить список извне).
- `decimal GetTotal()` — сумма `GetFinalPrice()` по всем позициям.
- `void PrintReceipt()` — печатает чек, вызывая у каждой позиции `GetInfo()` и `GetCategory()`.
- `decimal GetTotalWithDiscount(decimal percent)` — применяет скидку ко всем позициям, поддерживающим `IDiscountable`.

#### 5. `Main`

- Создать не менее 6 позиций разных типов, часть — с разными параметрами.
- Добавить их в `Order`.
- Напечатать чек и итоговую сумму.
- Применить скидку 10% и напечатать новую сумму.
- Продемонстрировать, что список из `GetItems()` нельзя изменить (раскомментировать строку с `Add` и показать, что компилятор/рантайм не даёт).

#### 6. Остальные требования

- Добавить класс `Combo` — набор из нескольких `MenuItem` со скидкой 15% на всё. `Combo` тоже наследуется от `MenuItem` и переопределяет `GetFinalPrice()` (сумма детей со скидкой).
- Добавить сортировку позиций по итоговой цене.
- Добавить метод `FindMostExpensive()` в `Order`, возвращающий самую дорогую позицию.
