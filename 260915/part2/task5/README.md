# Задача 5: 

Пользователь вводит три вещественных числа — коэффициенты квадратного уравнения `a`, `b` и `c` (вида `ax² + bx + c = 0`). Программа должна: 

- Проверить, что коэффициент `a` не равен нулю (иначе это не квадратное уравнение). 
- Вычислить дискриминант по формуле: `D = b² − 4ac`. 
- Вывести значение дискриминанта с точностью до двух знаков после запятой.

Дополнительно определить и вывести количество корней:
- если D > 0 — «Два корня»,
- если D = 0 — «Один корень»,
- если D < 0 — «Корней нет»
