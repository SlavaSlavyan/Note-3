# Задача 4: «Калькулятор с проверкой деления на ноль». 

Напишите программу, которая запрашивает у пользователя два числа (вещественные) и операцию: `+`, `-`, `*`, `/`. 

Программа должна выполнить соответствующее действие и вывести результат с точностью до трёх знаков. 

Важно: если выбрано деление и второе число равно нулю, программа не должна выполнять деление, а вместо результата выводить сообщение: "Ошибка: деление на ноль!".

Также программа должна корректно обрабатывать случай, когда пользователь ввёл неизвестную операцию — выводить: "Неизвестная операция".
